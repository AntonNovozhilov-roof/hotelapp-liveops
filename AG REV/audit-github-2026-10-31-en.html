What it does: accepts {message, room} → validates (empty / >2000 chars) → еслand no MODEL_API_KEY — returns mode: "MOCK" c mockTasks(); otherwise calls POST https://api.meta.ai/v1/chat/completions (muse-spark-1.3, temp 0.2) → parses JSON (with markdown-wrapper guard) → validateTasks() → saves via createStoredTasks() → {mode:"LIVE", tasks}.

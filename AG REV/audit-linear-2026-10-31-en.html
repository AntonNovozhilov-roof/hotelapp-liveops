1 — Overview Executive summary

What This Project Is

HotelApp LiveOps — an operations layer for small hotels (15–80 rooms). A guest sends a request via QR (text/voice) → AI routes it into tasks → staff executes → owner gets a briefing. Hackathon track: Meta Global AI Developer Hackathon 2026 · Build for Your World. The product must meaningfully use Meta AI — not just an idea.

How Work Is Organized

Everything lives in a single Linear team ANT (Anton-Novozhilov). Epic / Root Issue ANT-5 «Hotel App», with 8 sub-issues ANT-6…ANT-13. Assignee — agent Meta1 (Muse via opencode). Each sub-issue: create → In Progress → report comments → Done → DEVLOG.md + git commit (no push).

Verified: 9 ANT issues, 20 comments, status history; no projects/documents — normal for a hackathon

13 — Process & Hygiene Linear

Strengths

  • Status discipline: In Progress → Done only after verification, otherwise stays In Progress (see ANT-10).
  • Detailed comments: what was done, which files, how verified, what was NOT verified — rare level of honesty.
  • Agent signature: [Meta1] in titles + «Agent: Meta1 (Muse via opencode)» in commits — traceable.
  • DEVLOG.md in sync with Linear — every Done has a DEVLOG entry with date and ANT number.

What to Improve

  • Priorities & labels unused — all 9 issues are No Priority, no labels. With 5 days to deadline, set P0 = MVP, P1 = polish.
  • Assignee empty everywhere — owner not assigned on any issue; confusion when a second dev joins.
  • No due dates — hackathon deadline not in Linear; risk of missing it.
  • No estimates — helpful for planning the final 5 days.
  • No Projects/Cycles — overkill for hackathon, but one project "Meta Hackathon 2026" with target date would add clarity.
  • Canceled ANT-1…4 — Linear onboarding noise — can be archived/hidden.

ℹ Overall Spec Quality

Specs are concrete with success criteria and test plans — above average for a hackathon. Written in English, simple words, no jargon — jury-friendly. Iterations (ANT-11/12/13) show the product is tested, not just ticket-closed.

1 — Общая картина Executive summary

Что это за проект

HotelApp LiveOps — операционный слой для мини-отелей (15–80 номеров). Гость отправляет запрос через QR в номере (текст/голос) → AI маршрутизирует в задачи → персонал выполняет → владелец получает бриф. Трек хакатона: Meta Global AI Developer Hackathon 2026 · Build for Your World. Продукт должен реально использовать Meta AI, а не быть идеей.

Всё в одной команде Linear ANT (Anton-Novozhilov). Корневая задача ANT-5 «Hotel App», от неё 8 подзадач ANT-6…ANT-13. Исполнитель — агент Meta1 (Muse via opencode). Каждая подзадача: создать → In Progress → комменты с отчётом → Done → DEVLOG.md + git commit (без push).

13 — Процесс и гигиена Linear

Сильные стороны

  • Дисциплина статусов: In Progress → Done только после проверки, иначе остаётся In Progress (ANT-10 пример).
  • Детальные комменты: что сделано, какие файлы, как проверено, что НЕ проверено — редкий уровень честности.
  • Подпись агента: [Meta1] в заголовках + «Agent: Meta1 (Muse via opencode)» в коммитах — можно отследить кто что делал.
  • DEVLOG.md синхронен с Linear — каждое Done имеет запись в DEVLOG с датой и номером ANT.

Что улучшить

  • Приоритеты и лейблы не используются — все 9 задач No Priority, без лейблов. Для 5-дневного дедлайна стоит расставить: P0 = MVP, P1 = полировка.
  • Assignee пустой везде — владелец не назначен ни на одну задачу; при подключении второго разработчика будет путаница.
  • Нет due dates — дедлайн хакатона не в Linear; риск пропустить.
  • Нет estimate — для планирования финальных 5 дней полезно.
  • Нет Projects/Cycles — для хакатона избыточно, но один проект «Meta Hackathon 2026» с таргет-датой добавил бы наглядности.
  • Отменённые ANT-1…4 — системный шум Linear, можно архивировать/скрыть.

ℹ Общая оценка постановки

Постановки конкретные, с критериями успеха и тест-планом — уровень выше среднего для хакатона. Формулировки на английском, простые слова, без жаргона — жюри поймёт. Итерации (ANT-11/12/13) показывают, что продукт тестируют, а не просто закрывают тикеты.
